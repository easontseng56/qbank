新增題庫

把題庫 zip（內含 Tier 開頭的題庫資料夾、JSON 與 img）或單份 JSON 拖進下面的框，或按「選檔案」。zip 內已有題庫資料夾層時會自動放到對應位置；單份 JSON 要先選目標題庫。上傳後自動重新讀取，同名檔會覆蓋（＝更新）。

使用流程

  1. ①範圍與題數：勾章節、來源，填各題型目標題數，按「自動補題」。
  2. ②手動挑題（可略過）：逐題看全文、按「加入」。
  3. ③預覽試題：整卷排序、抽換、移除。
  4. ④試卷設定：考卷名稱、班級、版面，輸出題目卷／解答卷。
  5. 輸出題目卷時會自動記錄到「出題紀錄」並儲存考卷；之後可「載入考卷」改題再出。

其他說明

  • 啟動：雙擊「離線出題系統.exe」會自動開瀏覽器。備用：用 Chrome 開 index.html，按右上「選擇資料夾」選「離線出題系統」資料夾。
  • 題庫更新：把新的 JSON（和 img 資料夾）放進「題庫」下對應的題庫資料夾，再按「重新讀取題庫」；只會重讀有變動的檔。
  • 難度：把「難度\難度.json」放進資料夾後重新整理頁面即生效；篩選欄會多出「難度」。

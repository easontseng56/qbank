周逸化學工作室｜夥伴使用說明

從「把題目丟進來」到「成品上線」的完整流程，以及工作室各站怎麼用。

先講結論：你只要做一件事，把考卷丟進題庫池。其餘的轉錄、詳解、分類、排版、上網站，每週一早上 08:40 會自動跑完，成品出現在工作室各站。

① 丟進來

用「題庫池控制台」上傳，或直接丟進雲端 題庫池\01_待處理。

題目卷＋解答卷一起丟；急件請告訴 Eason。
② 自動處理

每週一 08:40 排程：判斷類型 → 逐題轉錄與詳解 → 分類 → 產 Word／PDF → 上網站 → 同步檢查。

通常當天完成，結果寫在控制台。
③ 到工作室拿成品

入口頁分「公領域」（公開網站）與「私領域」（內部工具）；出題、查卷、看進度都從這裡進。

1第一步：把題目丟進來

兩種方法擇一即可，效果一樣，都會進到同一個收件匣。

方法一：控制台上傳 推薦

  1. 開 工作室入口 → 右邊「私領域」→ 點「題庫池控制台」。
  2. 按「用 Google 登入」，使用工作室帳號。
  3. 在「上傳考卷」分頁把檔案拖進去（可一次多份，檔案再大也可以）。
  4. 「類型」不確定就選「自動判斷」；「備註」可寫補充，例如「只有題目卷，答案下週補」。
  5. 看到「已上傳」就完成，下方收件匣會列出你的檔。

方法二：丟進雲端資料夾

  1. 打開 Google 雲端硬碟的 claude共用資料夾\題庫池\01_待處理。
  2. 直接丟在根目錄，段考、模考、競賽混放沒關係，排程會自己分。
  3. 想指定類型也可以丟進子資料夾（段考／模考／競賽／歷屆／光碟），子資料夾名稱優先。

急件

一般件等週一排程。趕著要用的，上傳後直接告訴 Eason，他會請 Claude 立刻處理。

2第二步：系統自動做什麼

每週一 08:40（台北時間）排程啟動，沒有新卷也會跑一次同步檢查。你不需要做任何事。

收件與判類型1

掃 01_待處理 與合作的段考蒐集資料夾，看檔名＋前兩頁內文判斷類型。判不出來的標「待判定」問 Eason，不亂猜。

逐題轉錄＋詳解2

每題存成 JSON（唯一正本），寫簡答與詳解；圖與數據表用原卷截圖；題組拆開附共用題幹；每題加來源標籤，例如 【114-竹中-非選三-1(1)】。

分類3

依來源定 Tier（只升不降）、依課綱 76 小節定章節、標難度 1～5，再加素養、實驗、超範圍等標籤。

產出成品4

單卷 Word／PDF、總練習卷學生版與詳解版，全部加「周逸化學專用教材」浮水印。段考另產題目卷、解答卷。

上線＋同步檢查5

成品放雲端、網站自動更新；再以 JSON 為準，比對講義題庫、出題系統、各網站、目錄是否都一致。

回報6

控制台更新收件匣、同步狀態與儀表板；只有 Eason 能決定的事列在「待 Eason 處理」。處理過的檔搬到 _已處理\日期\。

?常見問題

丟進去之後多久會好？

每週一 08:40 開始跑，通常當天完成。急件告訴 Eason 可以不用等。

只有題目卷、沒有解答可以丟嗎？

可以，先丟，並在備註寫「答案之後補」。沒有解答的卷會先列在控制台等答案，補進來後再完成詳解與成品。

丟錯檔或重複丟了怎麼辦？

不用刪，告訴 Eason 即可。重複的卷系統會比對已建檔清單自動略過；判不出類型的會標「待判定」，不會亂處理。

怎麼知道我的卷處理好了？

控制台「上傳考卷」分頁下方的收件匣：處理完的檔會從「待處理」移到「最近處理完」；成品也會出現在對應網站與雲端 04_成品。

登入控制台或出題系統說沒有權限？

請確認用的是工作室帳號；換帳號可按右上角「換帳號」。還是不行就找 Eason 開權限。

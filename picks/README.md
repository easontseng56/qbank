# 周逸精選（好題標記，網頁版）

網址：https://easontseng56.github.io/qbank/picks/ （noindex，從 hub 私領域連過來）

- 本頁**不含任何內部資料**。登入 Google（沿用 `app/config.js` 的 clientId，與勘誤系統、控制台共用登入）後才讀寫雲端；對 題庫池 沒權限的帳號讀不到。
- 資料檔：`題庫池\07_紀錄\好題精選\好題清單.json`（第一次標記時自動建資料夾與檔案）。**不改題庫正本 JSON。**
- 找題：輸入題目標籤（可多個），只在雲端 `離線出題系統\題庫` 已建好的題庫裡找（沿用 app/drive.js、data.js、render.js）。
  完整標籤直接對卷；只寫學校的段考短標籤（114-竹中-單選5）依「年份＋校名」列出所有同題號的卷讓人選。
- 截圖辨識（2026-11-16）：上傳／拖曳／Ctrl+V 貼上截圖，在瀏覽器內用 Tesseract.js 5.1.1（jsDelivr，中文 chi_tra 約 10 MB，第一次下載後瀏覽器快取）辨識；先只留橘色字（柔性遮罩）、依行切開逐行辨識，沒有橘色字時辨識整張灰階圖。從文字抓「年份-卷別-題號」，「一」誤認成 - 、選字誤認等會修正，卷別再用題庫同年份卷名以編輯距離校正。結果只填進輸入框，不會自動加入精選。圖片不上傳。
- 每筆欄位：`id`（P0001…）、`key`（`卷檔名|標籤`，出題系統用它對題）、`tag`、`paper`、`path`、`bank`、`type`、`tiers`、`chapters`、`head`（題幹開頭）、`note`、`by`、`created`、`history`。
- 寫入一律「重讀最新版 → 套用 → 寫回」，降低多人同時編輯互蓋。取消精選＝刪掉該筆。
- 出題系統（app/app.js `loadPicks`、`applyPicks`）：登入後讀這份清單，對到的題目加上特殊標籤「周逸精選」（排第一個）與 ★ 精選標記；讀不到清單就略過。
